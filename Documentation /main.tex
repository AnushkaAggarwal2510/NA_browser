% Chapter 1
\chapter{Introduction}

JavaFX is a Java-based framework used to develop
graphical user interface applications. It provides
components such as buttons, text fields, menus,
and layouts.

NA Browser is a desktop web browser developed using
Java and JavaFX. It uses the WebView and WebEngine
classes to load and display websites within the
application window.

% Chapter 2
\chapter{Objectives}

The main objectives of the project are:

\begin{itemize}
    \item To develop a simple and user-friendly
    desktop web browser.
    \item To understand JavaFX GUI development.
    \item To implement URL loading and web navigation.
    \item To provide Back, Forward, and Refresh
    functionality.
    \item To understand event handling in Java.
\end{itemize}

% Chapter 4
\chapter{System Design}

The browser consists of the following components:

\begin{itemize}
    \item \textbf{User Interface:} Provides the
    address bar and navigation buttons.
    \item \textbf{WebView:} Displays web pages.
    \item \textbf{WebEngine:} Loads URLs and
    manages web navigation.
    \item \textbf{Event Handlers:} Respond to
    button clicks and user input.
\end{itemize}

\section{Workflow}

\begin{enumerate}
    \item The user opens NA Browser.
    \item The browser interface is displayed.
    \item The user enters a website URL.
    \item WebEngine loads the requested website.
    \item WebView displays the web page.
    \item The user navigates using the available controls.
\end{enumerate}

% Chapter 5
\chapter{Implementation}

\section{Application Window}

The Stage class creates the main application window,
while the Scene class contains the user interface.

\section{Web Page Display}

The WebView class displays web content, and the
WebEngine class loads and controls web pages.

\section{Navigation Controls}

Buttons are used to implement Back, Forward, and
Refresh operations through event handlers.

\section{URL Handling}

A text field allows users to enter website addresses.
The entered URL is passed to WebEngine to load
the requested page.

\section{Testing}

The browser should be tested for website loading,
URL input, navigation controls, and handling of
invalid URLs.

% Conclusion
\chapter{Conclusion}

NA Browser demonstrates the development of a desktop
application using Java and JavaFX. The project
provides practical experience with GUI components,
event handling, and web page integration.
